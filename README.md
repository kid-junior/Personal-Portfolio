# 💼Personal-Portfolio

A modern, multi-page personal portfolio showcasing my growth as an aspiring full-stack developer from Ethiopia. Built with HTML, CSS, and JavaScript, featuring a Minecraft-inspired design combined with clean layouts, responsive styling, and smooth interactions.

Created as part of the <a href="https://roadmap.sh/projects/portfolio-website">Roadmap.sh</a> project
<hr>

🛠 **Technologies**

<ul>
  <li><strong>HTML5</strong> – semantic and accessible structure</li>
  <li><strong>CSS3</strong> – responsive layouts, glassmorphism, animations</li>
  <li><strong>JavaScript</strong> – interactive UI behavior</li>
  <li><strong>Tools & Services</strong>
    <ul>
      <li><strong>Font Awesome</strong > – icons</li>
      <li><strong>Google Fonts</strong > – typography</li>
      <li><strong>Lottie</strong > – animations</li>
      <li><strong>Formspree</strong > – contact form handling</li>
    </ul>
  </li>
</ul>
<hr>

✨ **Features**
<ul>
  <li>Multi-page layout (Home, Projects, About, Contact)</li>
  <li>Minecraft-inspired theme with pixel fonts and glass effects</li>
  <li>Fully responsive design for all screen sizes</li>
  <li>Interactive navigation menu</li>
  <li>Optional background music toggle</li>
  <li>Functional contact form</li>
  <li>Clean and organized project structure</li>
</ul>
<hr>

🚀 **Running the Project**

**Option 1: Open Directly**
<ol>
  <li>Download or clone the repository</li>
  <li>Open `index.html` in any browser</li>
</ol>

**Option 2: Development Mode (Recommended)**
<ol>
  <li>Open the project folder in VS Code</li>
  <li>Install the Live Server extension</li>
  <li>Right-click `index.html` and select <strong>Open with Live Server</strong></li>
</ol>
