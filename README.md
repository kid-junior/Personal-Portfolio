# Personal-Portfolio
This is my personal portfolio website, showcasing my journey as an aspiring full-stack developer from Ethiopia. Built with HTML, CSS, and a dash of JavaScript for that extra polish—think Minecraft-inspired design with glassmorphism and interactive elements.

Created as part of the 👉<a href="https://roadmap.sh/projects/portfolio-website" target="_blank">Roadmap.sh</a>

✨<a href="https://kid-junior.github.io/Personal-Portfolio/" target="_blank">Live Demo</a>)

The goal of this project is to demonstrate my growing skills in web development, from semantic HTML structure to responsive CSS styling and basic JS functionality, all while creating a fun, thematic site to highlight my projects and bio.
<hr>

📌 Project Overview

This is a multi-page personal portfolio site themed around Minecraft vibes (pixel fonts, blurred glass effects, and even optional background music). It puts my dev skills on display in a clean, engaging way.

Pages Included:

• Home (index.html) – Hero intro, quick about, and featured projects

• Projects (projects.html) – Detailed project cards with links and placeholders for upcoming work

• About Me (about_me.html) – Bio, skills list, and goals grid

• Contacts (contacts.html) – Contact form (via Formspree), social links, and location info
<hr>

🛠 Tech Stack

• HTML5 (semantic structure for accessibility)

• CSS3 (glassmorphism, grids, media queries for responsiveness, custom animations)

• JavaScript (music toggle, hamburger menu, form submit effects)

• External Tools: Font Awesome icons, Google Fonts, Lottie animations, Formspree for forms
<hr>

🎯 Purpose of the Project

• Showcase my evolution from basic HTML to a styled, interactive site

• Practice real-world web dev: File organization, navigation, responsiveness, and user engagement

• Build a professional online presence to attract collaborations or gigs on Upwork/LinkedIn

• Experiment with themes (Minecraft aesthetic) to blend creativity with code

• Set up for future upgrades (e.g., adding backend with Node.js or React)
<hr>

🚀 How to Run the Project

Option 1: Open Directly

1. Download or clone the repository

2. Open index.html in any browser (assets like images/audio should load fine)

Option 2: Using VS Code (Recommended for Dev Mode)

1. Open the project folder in VS Code

2. Install the Live Server extension if you don't have it

3. Right-click index.html and select "Open with Live Server" – this handles local paths perfectly and auto-reloads on changes
